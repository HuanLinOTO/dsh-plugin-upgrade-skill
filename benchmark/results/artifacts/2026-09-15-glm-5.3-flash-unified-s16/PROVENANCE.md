## Arms and interleaving

8 Harbor jobs × 8 tasks × 1 attempt = 64 trials. Arm order alternates at job
level and reverses in round 2 (ABBA-style): `r1-noskill-a → r1-withskill-a →
r1-noskill-b → r1-withskill-b → r2-withskill-b → r2-noskill-b → r2-withskill-a →
r2-noskill-a`. Each task appears exactly twice per arm across the two rounds.

## Selection disclosure (drawn before any new score existed)

The draw reads only `task.toml` metadata and fixture sizes — no score artifact
is readable by the selector. Strata: problem family × fixture-size tercile with
proportional quotas; balance constraints: ≥2 hard tasks, ≥2 Chinese-prompt
tasks, ≥2 large-fixture tasks. Excluded by the seeded draw: S3, S4, S7, S8, S10,
S16. For transparency: the excluded set contains S4, the historically largest
positive lift (+62), and S16 (+20) — the draw was not tuned against or for any
historical outcome, and the same seed always reproduces it.

## Execution protocol

1. Pilot: run `r1-noskill-a` then `r1-withskill-a`. If any trial hits the task
   `timeout_sec` ceiling, stop; pre-register a raised timeout as a committed
   `task.toml` change applied to both arms, then restart the full 64-trial run.
   The pilot jobs are re-run as part of the formal run only if no budget change
   was needed; otherwise all 64 cells run under the new policy.
2. Formal: run the 8 jobs in `schedule.json` order, collecting each trial's
   final `report.md` into `reports/<arm>/r<repeat>/<task>/report.md`.
3. Grade: `node benchmark/scripts/grade-unified-run.mjs` (unified report-judge,
   arm-blind staging). Retry policy: infrastructure judge errors are re-run;
   solver trials are never retried (one attempt per cell, stop reason recorded).
4. Analyze: `node benchmark/scripts/analyze-unified-paired.mjs` →
   `paired-analysis.json` / `.md`.

Nothing in this directory may be regenerated after scores exist except through
the committed deterministic scripts (`--check` must stay green). Raw reports,
judge `details.json` per cell and this provenance file are the evidence trail.
